# C1. One preservation equation, many geometries

*Supporting connection. Rewritten at Gate 3 around bilinear forms.*

## Statement

A transformation $A$ preserves a bilinear form $B(u, v) = u^T M v$ when

$$B(Au, Av) = B(u, v) \quad \text{for all } u, v \qquad\Longleftrightarrow\qquad A^T M A = M.$$

The two sides are the same condition, because entry $(A^TMA)_{ij}$ is exactly $B(Ae_i, Ae_j)$ (card C1b). The same algebraic equation encodes different geometries, depending on what kind of form $M$ is:

| Kind of form | Example $M$ | What is preserved | Geometry | Cards |
|---|---|---|---|---|
| Symmetric positive-definite | $I$; a weighted $M$ | $B$, hence the quadratic $x^TMx$, which is never 0 for $x \ne 0$ | circles and ellipses; rotations; Parseval as a unitary map | S4b, S4e, S9, B1b |
| Symmetric indefinite | $\eta = \operatorname{diag}(1,-1)$ | $B$, hence $x^TMx$, which can be 0 for $x \ne 0$ (null vectors, [C5](C5.md)) | hyperbolas and light cones; boosts | S4c, S4f, S9, B1c, B1d |
| Antisymmetric (symplectic) | $J = \begin{pmatrix}0&1\\-1&0\end{pmatrix}$ | $\omega(u, v) = u^TJv$. **Not** a quadratic: $x^TJx = 0$ for every real $x$ (C1a) | phase-space area; Hamiltonian flow | S9, C1a, C1c |
| A metric varying from point to point | Fisher $g(\theta)$ | $g(\theta)$ at one point only | the model manifold | none yet |

**The symplectic row matters.** Checking the quadratic $x^TJx$ cannot detect symplectic structure. $\operatorname{diag}(2, 1)$ keeps $x^TJx = 0$ (trivially) but doubles $\omega$: $D^TJD = 2J$. A true Hamiltonian flow keeps $A^TJA = J$ (card C1c).

## Where it breaks or needs care

- **Varying metrics.** With $M = g(\theta)$, $A^T g(\theta) A = g(\theta)$ still makes sense *at one point*: it picks out the linear maps of that tangent space that preserve the metric there. But a curved model manifold generally has no maps of the whole manifold that preserve $g$ everywhere. **Pointwise metric preservation is not automatically a global symmetry.**
- **Kinds of preservation are not interchangeable** (Gate 3). Quadratic invariance, symplectic preservation, metric invariance and Noether conservation are connected through this equation, but none of them can stand in for another. The symplectic row shows why: the quadratic check passes there while the structure is not preserved.

## What an interactive would show

One equation, one live check ($\max |(A^TMA - M)_{ij}|$), and four geometries:

| Form | 3D view |
|---|---|
| Positive-definite | the bowl $z = x^TMx$ with orbit rings |
| Indefinite | the saddle, with null lines at height 0 |
| Symplectic | a patch of phase space whose **area** is the readout, because there is no height surface to draw ($x^TJx \equiv 0$ is flat) |
| Fisher | a field of metric ellipses on the model manifold, which changes from point to point |

## What would move it up a level

**Varying-metric row.** A card that computes the metric-preserving maps at two points of the exponential model manifold and tests whether any global map carries one point's metric to the other's. A FAIL would be kept, and it would sharpen the warning above.
